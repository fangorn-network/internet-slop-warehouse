# Source provenance

All fixture code, markup, styling, tests, level geometry and save fixtures were originally authored for the neutral Rescue Relay benchmark fixture on 2026-11-17. No source or assets were copied from the Internet Slop Warehouse, its parts, or any prior benchmark condition output. No external packages, fonts, assets or runtime services are used. The FNV-1a checksum is a conventional noncryptographic corruption check, not a security primitive.

All files are offered under CC0-1.0; see LICENSE. Node.js is used only to build and test. An optional static HTTP server is an operator tool, not a game dependency. The generated v1 standalone page can be opened directly without a server.
